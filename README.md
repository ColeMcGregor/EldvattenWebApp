# EldvattenWebApp

A private web app for the Eldvatten SCA group, built to support community communication, event coordination, and membership management.

The project is being developed as a volunteer effort and will be self-hosted on a Linux server owned by the group.

The app will include a public-facing website, a community blog/feed, event tools, and role-based access control for members and administrators.
